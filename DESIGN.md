# indianLudo v1 — Design

## Tokens
- Colors: P1 red `#E53935`, P2 green `#43A047`, P3 yellow `#FBC02D`,
  P4 blue `#1E88E5`; extras cycle. Board cream `#FFF8E1`, track white,
  safe star gold, text `#212121`.
- Type: display 28/bold, title 20/600, body 14, caption 12.
- Spacing 8pt grid; radius 12 cards, 8 buttons; elevation 2/4.

## Screens
1. Home: logo, Play Local / Play Online / How to Play buttons.
2. Setup: player count stepper, N-sided picker (2–10), house preview,
   Start button.
3. Board: board canvas center, shared dice-pool strip (last 5 rolls +
   Roll button), turn banner, capture toasts.
4. Result: winner banner, standings list, Play Again / Home.

## Board language
Classic cross-and-circle board, Indian palette (cream + jewel colors).
Diagonal pairing shown with matching corner badges for 2p-10side mode.
Tokens = flat discs with white ring; active token pulses. Safe squares
carry a gold star; home columns use player color gradients. Dice pool
strip is horizontal chips; current roll enlarges with a pop animation.
